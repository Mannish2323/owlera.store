# OWLERA Design & Inspiration References

> **CRITICAL DIRECTIVE:** Treat these as external reference websites, NOT installable agent skills or component dependencies. Never copy another brand's identity, logos, or proprietary assets. Keep OWLERA's own quiet luxury Indian lifestyle brand identity strictly intact.

## Brand Grounding Guidelines

1. **Brand Continuity:** All typography must remain *Cormorant Garamond* (headings) and *Inter* (body/UI).
2. **Palette Preservation:** Never apply color palettes from reference sites. Use only OWLERA's locked brand tokens (`--warm-ivory`, `--soft-cream`, `--warm-cream`, `--deep-charcoal`, `--bronze-gold`, `--light-champagne`, `--forest-green`).
3. **Emblem Protection:** The Monoline Diamond Owl Emblem and Hanging Logo Pendant are unique hallmarks of OWLERA and must never be swapped for external iconography.
